The **Agent Network Protocol** (**ANP**) is a decentralized discovery and collaboration layer for AI agents, focused on identity, trust, and interoperable agent graphs.

## Core concepts

- **Decentralized identity**: Agents use DIDs and verifiable credentials to establish trust.
- **Semantic agent graphs**: JSON-LD graphs describe capabilities, reputation, and relationships.
- **Open discovery**: Agents can be found across networks without centralized registries.
