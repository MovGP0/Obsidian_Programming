OkCupid measures how first-message length relates to reply probability. It then compares the extra reply chance with the extra time needed to write a longer message.

## Key findings

- Longer messages received more replies, but the gain became smaller as length increased.
- Short messages gave a better return per unit of writing time.
- The post separates response probability from effort efficiency.

## Algorithm relevance

This is an example of objective selection. A recommender can optimize for reply rate, user effort, or total successful conversations, and these objectives can produce different ranks.
