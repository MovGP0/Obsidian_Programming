OkCupid uses a statistical counterfactual to estimate how message patterns could change if racial groups had equal population sizes.

## Key findings

- Population size affects the number of available same-group and cross-group contacts.
- Per-capita popularity and network composition are different effects.
- The counterfactual depends on model assumptions and is not an observed experiment.

## Algorithm relevance

Candidate-pool composition affects recommendations and observed outcomes. Evaluation must separate individual preference from exposure and availability.
