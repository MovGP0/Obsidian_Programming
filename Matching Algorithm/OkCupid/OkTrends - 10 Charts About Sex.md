OkCupid uses ten charts to describe patterns in sexual attitudes and behavior. The post compares age, gender, orientation, relationship status, and question answers. It shows how a large answer catalog can support many secondary analyses beyond pair scoring.

## Key findings

- Answer distributions change with age and demographic groups.
- Several charts combine stated preferences with behavioral or profile data.
- The results describe OkCupid users and do not establish causes.

## Algorithm relevance

The post shows the analytical value of the same question-answer data that supported compatibility scoring and question selection.
