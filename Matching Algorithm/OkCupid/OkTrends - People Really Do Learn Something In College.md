This micro-post plots correct answers to several knowledge questions by women's age. It is an outtake from the older-women article.

## Key findings

- Scores peaked near the mid-twenties in the displayed questions.
- The questions did not support the point of the parent article.
- The post openly reports this mismatch.

## Algorithm relevance

The outtake is useful methodological evidence: analysts should not select only features that support a preferred conclusion.
