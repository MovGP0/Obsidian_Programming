OkCupid describes product experiments that changed photo visibility and displayed match percentages. The experiments measured how presentation affected messages and conversations.

## Key findings

- Users acted differently when the displayed match percentage changed.
- Pairs with low computed compatibility sometimes communicated when shown a high score.
- Later conversation outcomes still contained information about the underlying score.

## Algorithm relevance

This is direct evidence that a displayed score changes user behavior. Offline match accuracy and online experiment outcomes must therefore be evaluated together.
