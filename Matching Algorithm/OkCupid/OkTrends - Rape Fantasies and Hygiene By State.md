The first OkTrends post maps user-submitted match-question answers by state. It also explains how OkCupid identified useful questions in its large catalog.

## Key findings

- The community submitted the questions.
- OkCupid described good questions as items on which people disagree and about which they feel strongly.
- Popular questions had very large answer counts, which supported stable aggregate estimates.

## Algorithm relevance

This is a primary source for the [[OkCupid Question Selection Algorithm]]. It supports a ranking based on population division and preference strength.
