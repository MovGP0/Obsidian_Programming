---
title: ISO 9660
---
**ISO 9660** is a file-system standard for read-only optical-media interchange, especially CD-ROMs and distributable disc images.

## Best suited for

- Highly compatible CD and DVD images
- Boot and installation media
- Read-only software distribution
- Archival images that must be readable by many systems

## Design

ISO 9660 defines volume descriptors, directory records, file placement, and multiple interchange levels for optical media. Its conservative base format maximizes compatibility. Extensions such as Joliet and Rock Ridge add longer names or richer Unix metadata, but readers must support the chosen extension.

## Advantages

- Very broad operating-system and device support
- Stable standard for read-only optical interchange
- Suitable for bootable and distributable images
- Simple immutable image model

## Limitations

- Primarily read-only
- The base format has restrictive names and metadata compared with modern file systems
- Extensions can reduce compatibility with old readers
- Not suitable for normal system, application-data, or continuously updated storage

## Choose ISO 9660 when

Use ISO 9660 for a read-only image that prioritizes optical and legacy compatibility. Prefer [[Universal Disk Format|UDF]] for modern optical media that requires larger files, richer metadata, or writable-media support. For compressed Linux system images, consider [[SquashFS]] or [[Enhanced Read-Only File System|EROFS]].
