# VS Code

VS Code is a practical editor for RustHDL/RHDL and generated Verilog projects.

## Recommended Extensions

- Rust Analyzer
- Even Better TOML
- crates
- Verilog-HDL/SystemVerilog support
- WaveTrace or an external [[GTKWave]] workflow

Optional:

- Lushay Code can wrap OSS CAD Suite for some FPGA boards, but manual scripts are clearer for custom `GW2A-18C` work.

## Setup Notes

- Use the integrated terminal after activating [[OSS CAD Suite]].
- Keep build commands in PowerShell scripts or task definitions.
- Treat generated Verilog and `.cst` files as first-class project artifacts.
