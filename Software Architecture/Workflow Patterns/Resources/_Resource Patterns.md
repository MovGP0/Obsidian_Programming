---
title: Resource Patterns
---
Resource patterns describe the human and system-facing side of workflow enactment: who may receive work, how work is offered or allocated, when execution begins, how responsibility can move, what a resource can see, and how several resources coordinate on the same work item. They complement control-flow patterns by making resource policy explicit instead of treating people, roles, queues, and automated actors as an implementation detail.

Use these patterns when a process model must say more than "task A happens before task B." A robust workflow model usually needs to capture eligibility, authority, allocation timing, queue visibility, escalation, delegation, workload balancing, and whether a task starts automatically or waits for a resource decision.
