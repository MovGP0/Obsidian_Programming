---
title: Game Theory
---
**Game theory** studies strategic interaction between decision makers.

Each agent's best action can depend on what other agents do.

## Common model types

| Model | Use |
| ----- | --- |
| Normal-form game | One-shot simultaneous choices. |
| Extensive-form game | Sequential choices with a game tree. |
| Stochastic game | State evolves and agents act over time. |
| Cooperative game | Agents can form coalitions or share payoff. |

## Equilibrium

A common solution concept is Nash equilibrium: no agent can improve its payoff by changing strategy alone, assuming the other strategies stay fixed.

## Use when

- incentives matter,
- opponents adapt,
- coordination or competition is central,
- no single agent controls the outcome.

For algorithmic game-tree search, see [[Minimax Search]], [[Negamax Search]], and [[Monte Carlo Tree Search]].
