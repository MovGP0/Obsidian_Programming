---
title: Multiagent Decision Making
---
**Multiagent decision making** studies decisions where several agents act and each agent's outcome depends on what others do.

The key difference from single-agent planning is strategic interaction.

## Core questions

| Question | Concept |
| -------- | ------- |
| What should one agent do if others are rational? | [[Game Theory]] |
| Which action maximizes expected utility under uncertain evidence? | [[Decision Networks]] |
| Which observation is worth buying or gathering? | [[Value of Information]] |
| How should an agent act under uncertain state and outcomes? | [[Markov Decision Processes]] |
| What if the state is partially hidden? | [[Partially Observable Markov Decision Processes]] |
| How do many agents coordinate or compete? | [[Multiagent Systems]] |

## Single-agent vs. multiagent

In a single-agent model, the environment is not trying to respond strategically. In a multiagent model, other agents may learn, adapt, cooperate, bluff, punish, or exploit.

## Use when

- multiple decision makers interact,
- incentives matter,
- opponents or collaborators adapt,
- equilibrium or coordination matters more than one optimal path.
