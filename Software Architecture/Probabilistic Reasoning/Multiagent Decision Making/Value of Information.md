---
title: Value of Information
---
**Value of information** measures how much an observation is worth before making a decision.

Information is valuable when it can change the chosen action and improve expected utility.

## Expected value of perfect information

The value of perfect information for an unknown variable $X$ is the expected gain from knowing $X$ before acting.

Conceptually:

```text
value = expected utility with information
      - expected utility without information
```

## Use when

- tests, sensors, experiments, or scouting actions cost resources,
- more evidence may change the decision,
- uncertainty is expensive,
- the system must decide whether to observe or act now.

Value of information connects [[Expected Utility]], [[Decision Networks]], and active information gathering in [[Partially Observable Markov Decision Processes]].
