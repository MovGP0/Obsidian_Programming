**Code Hoarders** summarizes clean-code-style guidance from [Code Hoarders](https://blog.cleancoder.com/uncle-bob/2014/04/03/Code-Hoarders.html).

Unused code is inventory that obscures current behavior. Clean codebases delete dead paths and rely
on version control rather than keeping speculative or obsolete code around.

## Style Guidance

- Remove dead code instead of commenting it out or preserving it for imagined future use.
- Trust version history for recovery.
- Keep the working tree focused on behavior the system actually uses.
