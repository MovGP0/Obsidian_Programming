**The Principles of Craftsmanship** summarizes clean-code-style guidance from [The Principles of Craftsmanship](https://blog.cleancoder.com/uncle-bob/2013/02/10/ThePrinciplesOfCraftsmanship.html).

Craftsmanship frames clean code as professional responsibility: developers should steadily improve
skill, care about quality, and leave systems better than they found them.

## Style Guidance

- Treat readability and maintainability as professional obligations.
- Improve code quality incrementally during normal work.
- Use practice, feedback, and shared standards to raise the quality bar.
