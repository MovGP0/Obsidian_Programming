**The Cycles of TDD** summarizes clean-code-style guidance from [The Cycles of TDD](https://blog.cleancoder.com/uncle-bob/2014/12/17/TheCyclesOfTDD.html).

TDD operates at multiple rhythms: tiny code cycles, broader refactoring cycles, and larger feature
cycles. Clean code depends on honoring all of them rather than stopping at green tests.

## Style Guidance

- The smallest cycle keeps behavior changes safe.
- The refactoring cycle keeps the codebase clean after tests pass.
- Larger cycles connect the implementation work back to business-facing progress.
