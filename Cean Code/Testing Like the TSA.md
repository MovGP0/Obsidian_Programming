**Testing Like the TSA** summarizes clean-code-style guidance from [Testing Like the TSA](https://blog.cleancoder.com/uncle-bob/2017/03/06/TestingLikeTheTSA.html).

Testing should be risk-aware and feedback-oriented. More process and more checks do not
automatically create better confidence if they target the wrong risks.

## Style Guidance

- Use tests to shorten feedback about likely failures.
- Prefer focused automated checks over ritualized broad inspection.
- Ask what risk a test reduces before adding it to the suite.
