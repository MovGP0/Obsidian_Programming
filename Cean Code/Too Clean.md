**Too Clean** summarizes clean-code-style guidance from [Too Clean?](https://blog.cleancoder.com/uncle-bob/2018/08/13/TooClean.html).

Cleanliness has a cost, but messy code has compounding interest. The practical point is not
ornamentation; it is keeping code easy enough to change safely.

## Style Guidance

- Do not confuse clean code with ceremony or decorative abstraction.
- Pay attention to whether a cleanup improves changeability, testability, or comprehension.
- Treat local messes as liabilities when they slow repeated work or hide defects.
